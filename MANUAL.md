# Ручные проверки

Что не накрыть автотестом: терминал, меню macOS, живой стенд. Пункт `man:…` —
шаги, исход и «Держит:»; договорённость со словами «руками»/«настоящий
терминал» обязана иметь пункт (`scripts/req.sh`). Прогонять перед релизом.

- `man:term-clean` — **Терминал без мусора.** `--tui` в настоящем терминале:
  журнал — в файл, экран чист; выход по `q` и паника возвращают терминал.
  Держит: `agr:term-quiet`, `agr:term-restore`.
- `man:menus` — **Меню и диалог macOS.** Файл — меню «Файл», «Последние»,
  перетаскиванием; «Линки resolve…» (F5) — список; диалог закрыт пустым — цел.
  Держит: `agr:open-without-file`.
- `man:detach` — **Окно не держит терминал.** Запуск из терминала: родитель
  вышел сразу, окно живо; `.app` (`scripts/bundle-macos.sh`) — без терминала.
  Держит: `agr:gui-detach`.
- `man:live-growing` — **Живой растущий файл** (`ssh 141`/`121`, mu0):
  `*.current.dat` листается и фильтруется без задержек; End/`r` у хвоста — на
  новую последнюю, без прыжков мимо конца.
  Держит: `agr:reload`.
- `man:glue-rotation` — **Склейка и фиксация живой ротации.** Открыть со стенда
  `текущий.current.dat-2`, поправить поле в старой части и зафиксировать тегом:
  рядом легли `*.{M}.patched.dat` только для частей с правками. Собрать семью в
  чистом каталоге (переименовать `*.{M}.patched.dat` → `*.{M}.dat`, чистые части
  дополнить) и открыть rotate+-инструментом (`tll-read 'rotate+file://DIR/PREFIX'`)
  и mutator-ом — поток один, границы согласованы, дублей seq нет.
  Держит: `agr:glue-commit`.
- `man:agent-progress` — **Ход агента живой.** Окно и `--tui` на стенде,
  вопрос с поиском по файлу: ждём — переливаются точки «модель думает»;
  поиск — спиннер «инструмент search_messages · N с», затем «модель думает ·
  search_messages → N строк», в ленте строк инструментов нет; текст — спиннер
  «модель пишет» и курсор. Пустой ответ — красное «модель не ответила».
  Держит: `agr:agent-progress`, `agr:agent-empty`.
- `man:link-live` — **Живой линк на стенде** (`ssh 141`): `mutator
  resolve://SERVICE/CHANNEL` в окне и `--tui`. Справа в заголовке — Opening,
  потом Active · онлайн; хвост растёт, курсор стоит. `o` (форма) → `mode=seq;seq=N` —
  история с N, затем онлайн. Обрыв сети — Error с текстом, `r` дописывает с
  последнего seq. Неверный сервис — Error в заглушке и терминале. С `--keep
  DIR` спул остаётся, без — каталога `mutator-<pid>` после выхода нет.
  Держит: `agr:link-state`, `agr:link-open`, `agr:link-spool`.
- `man:resolve-browse` — **Список линков стенда** (`ssh 141`): `--resolve
  HOST:PORT` в окне, `--tui` и `--serve` (браузер, `curl /api/v1/resolve`):
  фильтр `gw/`, сортировка, Enter — линк Active, F5/Esc — список и назад;
  ушёл сервис — строки нет, упал сервер — Error, поднялся — список вернулся.
  Держит: `agr:resolve-browse`.
- `man:wui` — **Веб-UI в браузере.** `mutator --serve 127.0.0.1:8080 FILE`
  (сборка с `wui`), открыть `/`: «Просмотр» — экран как `--tui`, ↑↓ PgDn End,
  `f` фильтр, `/` поиск, Enter — деталь, `x` hex, F1 — справка, щелчок по
  строке; границу детали тянут мышью, Shift — выделить текст; `e` в детали —
  «только просмотр». Окно уже — сетка перестроилась.
  Вторая вкладка — свой вид. «API»: `count_messages` с `expr` — итог без
  перезагрузки; линк — состояние растёт. Сервер остановлен — «переподключение…».
  Два «Открыть» подряд — на экране второй. С `--token T` на `0.0.0.0`: `/` — 401,
  `/?token=T` — страница, токен из адреса пропал, кадры идут.
  Держит: `agr:serve-wui`, `agr:serve-view-desk`, `agr:serve-view-frames`,
  `agr:serve-token`.
